# คืนหมาป่า

เกมมนุษย์หมาป่าออนไลน์สำหรับเล่นกับเพื่อน มี 36 บทบาท คุยด้วยเสียงในเกม และระบบคุมเสียงตามช่วงเกม

ทั้งเกมอยู่ในไฟล์ `index.html` ไฟล์เดียว ไม่ต้องติดตั้งอะไรเพิ่ม และไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

---

## วิธีขึ้นเว็บด้วย GitHub Pages (ทำครั้งเดียว ประมาณ 5 นาที)

1. **สมัครหรือล็อกอิน** ที่ https://github.com
2. **สร้าง repository ใหม่:** กดปุ่ม **+** มุมขวาบน แล้วเลือก **New repository**
   - **Repository name:** ตั้งชื่ออะไรก็ได้ เช่น `kuenmapa`
   - เลือก **Public** (GitHub Pages แบบฟรีต้องเป็น Public)
   - กด **Create repository**
3. **อัปโหลดไฟล์**
   - ในหน้า repository กดลิงก์ **uploading an existing file**
   - ลากไฟล์ `index.html` ลงไป (จะใส่ `README.md` ด้วยก็ได้)
   - กด **Commit changes**
4. **เปิด GitHub Pages**
   - ไปที่ **Settings** แล้วเลือก **Pages** ในเมนูซ้าย
   - หัวข้อ **Build and deployment**:
     - **Source:** Deploy from a branch
     - **Branch:** `main` และโฟลเดอร์ `/ (root)`
   - กด **Save**
5. **รอ 1–2 นาที** แล้วรีเฟรชหน้า Pages จะมีลิงก์ขึ้นมา หน้าตาประมาณนี้:
   `https://ชื่อผู้ใช้ของคุณ.github.io/ชื่อrepo/` (ของห้องนี้คือ https://zgezix.github.io/were/)

เปิดลิงก์นั้นก็เล่นได้เลย เพื่อนไม่ต้องมีบัญชีอะไร

**ถ้าแก้ไฟล์ทีหลัง:** อัปโหลด `index.html` ทับไฟล์เดิมใน repository แล้วรอ 1–2 นาที

## วิธีเล่น

1. **โฮสต์:** ใส่ชื่อแล้วกด **สร้างห้องใหม่** จากนั้นกด **คัดลอกลิงก์** ส่งให้เพื่อน
2. **เพื่อน:** เปิดลิงก์ ใส่ชื่อ แล้วกด **เข้าห้อง**
3. **ทุกคนกดอนุญาตไมโครโฟน** เมื่อเบราว์เซอร์ถาม
4. **โฮสต์เลือกบทบาท** แล้วกด **เริ่มเกม**
   - ปุ่ม "จัดแนะนำตามจำนวนคน" ช่วยเลือกชุดบทบาทให้
   - ถ้าคนไม่ครบ เพิ่มบอทได้

**สำคัญ:** โฮสต์ต้องเปิดหน้าเกมค้างไว้ตลอด เพราะเครื่องโฮสต์เป็นผู้ดำเนินเกม
- ถ้าโฮสต์เผลอรีเฟรช ให้กด **กลับไปคุมห้อง** ที่หน้าแรก เกมจะเล่นต่อจากเดิม และเพื่อนจะเชื่อมกลับเข้ามาเอง
- เพื่อนที่หลุดก็กด **กลับเข้าห้อง** ได้เหมือนกัน

---

## บอทอัจฉริยะ

ถ้าคนไม่ครบ โฮสต์เพิ่มบอทได้ บอทในเกมไม่ได้กดมั่ว:
- **ช่วงเช้า:** บอทพิมพ์แชทคุยกัน มีป้าย "กำลังพิมพ์…" ขึ้นก่อนส่งข้อความ
  - กล่าวหาคนที่น่าสงสัย โดยดูจากประวัติโหวตและบทบาทของคนที่ตายไปแล้ว
  - แก้ตัวเมื่อโดนชี้
  - เห็นด้วยกับคนอื่น และถามคนที่เงียบ
- **ผู้หยั่งรู้บอท:** เปิดตัวบอกผลส่องเมื่อเจอหมาป่า
- **หมาป่าบอท:** หลอกเก่ง
  - ปกป้องเพื่อนหมาป่า และโยนความผิดให้ชาวบ้าน
  - อ้างตัวเป็นผู้หยั่งรู้ปลอมเพื่อสวนผู้หยั่งรู้ตัวจริง
  - ตอนกลางคืนชวนคุยในห้องฝูงหมาป่า ถ้ามีคนเล่นเป็นหมาป่าด้วย
- **อ่านแชทของคนจริง:** ถ้าพิมพ์ชื่อใครพร้อมคำอย่าง "หมาป่า" หรือ "สงสัย" บอทจะเอาไปคิด และบอทที่โดนชี้จะตอบโต้
- **อยากให้บอทคุยฉลาดขึ้นอีก:** โฮสต์ใส่ Claude API key ของตัวเองได้ที่ ตั้งค่า → AI บอท
  - คิดค่าใช้จ่ายตามการใช้จริงในบัญชี Anthropic ของคุณ
  - key เก็บในเครื่องโฮสต์เท่านั้น

## โหวตข้ามช่วงเช้า

ช่วงเช้ามีปุ่ม **โหวตข้ามช่วงเช้า** ถ้าโหวตข้ามเกินครึ่งของคนที่ยังมีชีวิต เกมจะเข้าสู่รอบโหวตประหารทันที บอทจะโหวตข้ามเองหลังพูดเสร็จ

## เครื่องกระตุก

เปิด **ตั้งค่า → โหมดลื่น** เพื่อลดแสง เงา และแอนิเมชันที่เล่นวนตลอด

## ระบบเสียง

### ตั้งค่า (ปุ่มสีส้มมุมบน)
- เลือกไมโครโฟน
- ทดสอบไมค์ด้วยแถบระดับเสียง และปุ่ม "ฟังเสียงตัวเอง" (ใส่หูฟังก่อน)
- เลือกลำโพงหรือหูฟัง และปุ่มทดสอบเสียงออก
- โหมดเสียง:
  - **เปิดไมค์ตลอด:** กดปุ่มลัดเพื่อเปิด-ปิดไมค์ ค่าเริ่มต้นคือปุ่ม M
  - **กดค้างเพื่อพูด:** ต้องกดปุ่มค้างไว้ตอนพูด
- เปลี่ยนปุ่มลัดได้
- ปรับความดังเสียงเพื่อนรายคน
- เสียงเอฟเฟคในเกมและระดับเสียง

### ใครได้ยินใคร (ระบบคุมให้อัตโนมัติ)

| ช่วงเกม | ใครได้ยินใคร |
|---|---|
| ห้องรอ / จบเกม | ทุกคนได้ยินกันหมด |
| กลางวัน / โหวต | คนที่ยังมีชีวิตพูดให้ทุกคนได้ยิน (ยกเว้นคนที่โดนเวทหรือโดนไล่ออกนอกหมู่บ้าน) |
| กลางคืน | **เฉพาะฝูงหมาป่าได้ยินกันเอง** ชาวบ้านไม่ได้ยินใครเลย และไม่มีใครได้ยินชาวบ้าน |
| คนตายแล้ว | พูดได้เฉพาะในหมู่วิญญาณ แต่ฟังคนเป็นได้ |

**กันไมค์หลุด**
- เครื่องโฮสต์เป็นผู้ตัดสินว่าใครส่งเสียงถึงใครได้
- ปิดทั้งฝั่งคนส่งเสียงและฝั่งคนฟัง
- ก่อนจะเข้าช่วงกลางคืน ระบบปิดเสียงทุกคนไว้ล่วงหน้าเสี้ยววินาที กันเสียงเล็ดลอดตอนเปลี่ยนช่วง

**บทบาทและแชทลับ:** เครื่องโฮสต์ส่งข้อมูลให้แต่ละคนเฉพาะส่วนที่คนนั้นควรรู้
- ชาวบ้านไม่ได้รับบทบาทของคนอื่น และไม่ได้รับข้อความในห้องหมาป่า
- เปิด DevTools ก็แอบดูไม่ได้ ยกเว้นเครื่องโฮสต์เองที่ถือข้อมูลทั้งเกมไว้

## ปัญหาที่อาจเจอ

**เพื่อนบางคนได้ยินเสียงแต่บางคนไม่ได้ยิน**
- เครือข่ายบางแบบ (เน็ตมือถือบางค่าย เน็ตบริษัท) บล็อกการเชื่อมต่อตรงระหว่างเครื่อง
- แก้โดยใส่ TURN server ใน **ตั้งค่า → ขั้นสูง** ให้ทุกคนใส่เหมือนกัน
- หา TURN ฟรีได้จากผู้ให้บริการอย่าง Metered (metered.ca) หรือ Cloudflare Calls

**เลือกหูฟังไม่ได้**
- Safari ยังไม่รองรับการเลือกอุปกรณ์เสียงออกในเว็บ แนะนำ Chrome หรือ Edge
- ใน Safari ให้เปลี่ยนอุปกรณ์เสียงที่ตั้งค่าของเครื่องแทน

**ไม่มีเสียงเพื่อนเลย**
- กดปุ่ม **เปิดเสียงเพื่อน** ใต้แชท (เบราว์เซอร์บางตัวต้องให้แตะจอก่อนถึงจะเล่นเสียงได้)

**สร้างห้องหรือเข้าห้องไม่ได้**
- เกมใช้เซิร์ฟเวอร์จับคู่สาธารณะของ PeerJS (ฟรี) ถ้าเซิร์ฟเวอร์นั้นล่มชั่วคราว ให้รอสักพักแล้วลองใหม่
- เสียงและข้อมูลเกมจะวิ่งตรงระหว่างเครื่องผู้เล่น ไม่ผ่านเซิร์ฟเวอร์นั้น

**รองรับกี่คน**
- ผู้เล่นสูงสุด 16 คน
- เสียงเป็นแบบทุกเครื่องต่อตรงหากัน ถ้าเกิน 10 คนแล้วเน็ตบางคนช้า แนะนำให้คนที่เน็ตแรงสุดเป็นโฮสต์
